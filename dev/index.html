AbstractCosmologicalEmulators.jl

ACE.jl is shorthand here for AbstractCosmologicalEmulators.jl, the shared Julia runtime layer in the CosmologicalEmulators ecosystem. The package name used in Pkg and using is AbstractCosmologicalEmulators.

ACE supplies trained-emulator interfaces, normalization and postprocessing, differentiable interpolation, and optional analytic-background calculations. It does not train emulators or replace a Boltzmann solver.

Two distinct neutrino interfaces

The trained neural artifacts take total neutrino mass with the training model's fixed splitting. The analytic background takes three individual physical masses, and supports explicit Neff prescriptions. These are not interchangeable models or input vectors.

Reactant is not a package-wide guarantee

Supported Lux/Generic emulator and spline paths have Reactant extensions. The analytic-background extension is host-only, and SimpleChains is not an XLA backend. See the compatibility table.

The guides contain executable examples and doctests. CI builds this same site with warnings treated as errors, in addition to the separate full package suite.
